# JavaScript and TypeScript

`.js`, `.jsx`, `.ts` and `.tsx` files get completion, errors as you type, documentation, Go to
Declaration, Find Usages, Rename and quick fixes, across the project:

- a Laravel front end in `resources/js`,
- a Vue or React app, or a Node tool, in a subfolder.

PHPBlitz reads their `tsconfig.json` or `jsconfig.json` (path aliases like `@/`) and the types of
their packages in `node_modules`.

The **npm** tool window lists each `package.json` with its scripts, and runs them in the
[terminal](./terminal). See [Composer and npm](./composer).
