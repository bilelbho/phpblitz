# Terminal

Real shells in tabs and splits: PowerShell, cmd, Git Bash, WSL, bash, zsh… Open it with
<kbd>Alt+F12</kbd>.

- **Tabs and splits**: **+** opens a tab, ▾ picks another shell; drag a tab onto the terminal to
  split it, side by side or one above the other. Double-click a tab to rename it.
- **File paths are links**: `User.php:12`, stack traces and error messages open in the editor at
  that line on click.
- **Find in the output**: <kbd>Ctrl+F</kbd>.
- **Jump between commands**: <kbd>Ctrl+↑</kbd> / <kbd>Ctrl+↓</kbd>. A line separates commands, and a
  red bar marks the output of one that failed.
- **Copy Last Command Output** is one right-click away.

*Settings ▸ Tools ▸ Terminal* sets the shell, the start folder, environment variables, the font, and
whether keys typed in the terminal go to the shell instead of the IDE's shortcuts
(*Override IDE shortcuts*). Some keys always reach the IDE, like <kbd>F6</kbd> to move to the next
panel.
