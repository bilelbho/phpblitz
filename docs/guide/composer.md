# Composer and npm

## Composer

The **Composer** tool window lists the installed packages and the updates available
(*Check Composer Updates*). The packages' output shows in the bottom **Composer** log.

A project without `vendor/` says so and offers *Run composer install*, instead of showing errors
about unknown classes.

## npm

The **npm** tool window lists each `package.json` in the project with its scripts. Click one to run
it in the [terminal](./terminal).
